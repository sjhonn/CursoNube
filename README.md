# 🏠 Bienes y Raíces Web App

Aplicación web desarrollada en Python (Flask) para la gestión de bienes raíces, que permite a los usuarios registrarse, iniciar sesión y gestionar información relacionada a propiedades y documentos (boletas), integrando servicios de Firebase.

---

## 🚀 Características

- Autenticación de usuarios (login / registro)
- Subida de documentos (boletas)
- Descarga de comprobantes
- Visualización de bienes raíces
- Integración con Firebase (backend y almacenamiento)
- Interfaz web con templates HTML

---

cd Bienes_y_Raices
